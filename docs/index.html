How it works

Three steps, zero training

The Admin approval toggle on the dashboard controls the flow: OFF (default) = customers self-serve with a PRINT reply. ON = every file waits for your preview + Approve & Print.

📩

1. Customer sends file

PDF, photo or Office doc to your linked WhatsApp number.

→
🤖

2. Bridge decides

Auto-prints on valid PRINT reply, or holds for admin approval + safeguards.

→
🖨️

3. CUPS prints

BW / Color + copies honored. Status sent back on WhatsApp.

Features

Built for real print shops

Everything a small shop needs — nothing it doesn't.

⚡

Auto-print mode

Approval OFF: customer replies PRINT [BW|COLOR] [COPIES N] and it prints instantly with a status reply.

🛡️

Admin approval mode

Approval ON: nothing prints without your preview + ✓ Approve & Print. Full control.

📊

Live dashboard

Queue at localhost:3001 — QR/pairing-code linking, printer picker, test print, retry & reprint. Refreshes every 3s.

📄

All common formats

PDF, JPG, PNG, WEBP, DOCX, PPTX, XLSX (Office via LibreOffice headless conversion).

🔒

Abuse safeguards

Oversize files, too many copies, queue floods and hourly caps auto-hold for review — tunable in .env.

💻

Runs anywhere

Windows laptop (SumatraPDF), Mac, Linux, Raspberry Pi & Docker. Your data stays in inbox/, session in auth/.

Get started

Up and printing in 5 minutes

Clone the repo, configure one file, link WhatsApp. Pick your platform:

git clone https://github.com/coderjks/whatsapp-print-bridge.git
cd whatsapp-print-bridge
:: double-click start-windows.bat  (installs Node LTS if missing)
:: …then open http://localhost:3001, link WhatsApp, pick printer, Test print

Needs: a printer installed in Windows + LibreOffice for Word/Excel/PowerPoint (download). Keep the black window open during shop hours.

git clone https://github.com/coderjks/whatsapp-print-bridge.git
cd whatsapp-print-bridge
cp .env.example .env   # set PRINTER_NAME, ALLOWED_NUMBERS
npm install && npm run dev
# scan QR at http://localhost:3001 with WhatsApp > Linked devices

Needs: Node 20+, CUPS printer (lpstat -p -d), LibreOffice (brew install --cask libreoffice). Or just run ./start-macos.sh.

FAQ

Questions, answered


Is it free? What's the catch?

Yes — MIT-style open source, no per-page fees. You host it yourself on a shop PC or Pi. It uses the unofficial Baileys WhatsApp client, so use a spare shop number and be ready to re-link if WhatsApp changes things.

How do customers print without an account?

They just send the file to your linked number. With approval OFF the bot asks them to reply PRINT with options; with approval ON you approve from the dashboard after previewing.

No camera for QR? How do I link?

Set WHATSAPP_NUMBER=919876543210 in .env and restart — the dashboard shows an 8-digit pairing code. Enter it via WhatsApp → Linked devices → Link with phone number. You can also enter any number + "Get pairing code" right in the dashboard.

How do I host this page + publish the code?

Push this repo to GitHub, then enable Settings → Pages → Deploy from branch → main → /docs. This page lives in docs/index.html so it goes live instantly at yourname.github.io/whatsapp-print-bridge.
