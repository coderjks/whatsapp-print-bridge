How it works

A workflow your staff already understands

The Admin approval toggle on the dashboard controls the flow. OFF (default) — customers self-serve with a PRINT reply. ON — every file waits for your preview and approval.

01

Customer sends a file

PDF, photo or Office document to your linked WhatsApp number. No app or account needed.

→
02

Bridge routes it

Valid PRINT reply prints immediately; oversized or over-limit jobs are held for admin review.

→
03

Printer delivers

Black & white or color, with copy count honored. Status is sent back on WhatsApp.

Capabilities

Everything a print counter needs

One service handles intake, approval and printing — with safeguards against abuse.

Auto-print mode

Approval OFF: a valid PRINT [BW|COLOR] [COPIES N] reply prints instantly, with a status confirmation.

Admin approval mode

Approval ON: nothing prints without preview and confirmation. Full control for staffed counters.

Live dashboard

Queue at localhost:3001 — WhatsApp linking, printer selection, test print, retry and reprint. Auto-refreshes.

All common formats

PDF, JPG, PNG, WEBP, DOCX, PPTX, XLSX. Office files convert headlessly via LibreOffice.

Abuse safeguards

File-size, copy-count, queue-depth and hourly caps auto-hold jobs for review. Tunable in .env.

Runs anywhere

Windows, macOS, Linux, Raspberry Pi and Docker. Queue in inbox/, session in auth/.

Setup

Up and printing in about five minutes

Clone the repository, configure one file, link WhatsApp. Select your platform:

git clone https://github.com/coderjks/whatsapp-print-bridge.git
cd whatsapp-print-bridge
:: double-click start-windows.bat  (installs Node LTS if missing)
:: open http://localhost:3001, link WhatsApp, pick printer, Test print

Requirements: a Windows-installed printer + LibreOffice for Office files (download). Keep the app window open during shop hours.

git clone https://github.com/coderjks/whatsapp-print-bridge.git
cd whatsapp-print-bridge
cp .env.example .env   # set PRINTER_NAME, ALLOWED_NUMBERS
npm install && npm run dev
# scan QR at http://localhost:3001 with WhatsApp > Linked devices

Requirements: Node 20+, a CUPS printer (lpstat -p -d), LibreOffice (brew install --cask libreoffice). Or run ./start-macos.sh.

Linux / Pi shares host CUPS via /var/run/cups. On macOS use ipp://host.docker.internal:631.

FAQ

Questions, answered


Is it free? What's the catch?

Yes — open source with no per-page fees. You host it on your own PC or Raspberry Pi. It uses the community Baileys WhatsApp client, so use a dedicated shop number and expect to re-link if WhatsApp changes something.

How do customers print without an account?

They send the file to your linked number. With approval OFF, the bot asks for a PRINT reply and prints. With approval ON, staff approve from the dashboard after previewing.

No camera for QR — how do I link?

Set WHATSAPP_NUMBER=919876543210 in .env and restart. The dashboard shows an 8-digit pairing code — enter it via WhatsApp → Linked devices → Link with phone number. You can also request a code for any number from the dashboard.

How is this page hosted?

This page is a single static file at docs/index.html. Enable Settings → Pages → Deploy from branch → main → /docs and it goes live at coderjks.github.io/whatsapp-print-bridge.
